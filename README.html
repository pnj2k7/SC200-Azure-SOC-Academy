SC200 Azure SOC Academy

An 18-day, scenario-led security operations programme for corporate training and individual study. Build and investigate a fictional hospital environment using Azure, Microsoft Sentinel and the Microsoft security portfolio. No prior security-job experience is assumed; basic computer use and willingness to read technical steps are required.

Start with Getting started, then open the HTML course. Download the repository ZIP from GitHub, extract it and double-click index.html. The pages work offline; Microsoft portals require internet and appropriate accounts. handbook.html is a single-file reading edition with embedded styles.

Coverage and honesty

The official baseline is the SC-200 skills outline effective 21 October 2026, checked 25 October 2026. Microsoft lists three weighted areas and nine objective groups. This course organises them into 12 teaching modules, not 12 official exam domains. Coverage maps all 54 listed objective bullets to a lesson and evidence requirement. Related exam topics may extend beyond the published bullets.

Live, Simulation and Pending statuses are separate. An Azure subscription does not supply every Defender, Microsoft 365, Purview, Entra, AI or advanced platform license. Simulated work supports learning but does not prove operational competence on a live product.

Scenario and assessment

Wardlight Hospitals is fictional. Its hospital services must remain available while its security team investigates a suspicious supplier invoice. Portfolio and capstone assess evidence and judgement. Nothing in this repository is an official Microsoft exam question or a guarantee of a pass.

Repository map

  • scenario/: organisation and numbered architecture.
  • days/day-1 through day-18/: lesson, notes, lab, slides, quiz and exercise.
  • days/review/: coverage review and assessment.
  • coverage/: objective matrix and module map.
  • infra/, scripts/, queries/, notebooks/, data/: downloadable practical assets.
  • templates/: evidence, access, cost, incident and change records.
  • coursework/, practice/, artefacts/: assessments and interactive learning.
  • Publishing, cleanup, sources and attribution.

Run python build_course.py to regenerate static pages, then python scripts/validate.py. No package installation is required. Python 3.10+ is recommended. Deployment templates and cloud workflows require validation in your own isolated subscription; local checks do not prove Azure deployment or licensed product actions.

Professional use

Use a dedicated training tenant/subscription. No production connections, real patient data, passwords, tokens or unredacted evidence in Git. An organisation should have a security owner review permissions, licensing, regional availability, cost and change approval before corporate rollout. Corporate delivery guide provides the operating model.
