# Day 11: Find the data trail

Finding a file and proving that someone downloaded it are different tasks. Use the right record for each question and collect only the information the investigation needs.

## Your mission

A fictional export might contain patient identifiers. Investigate audit, content, Graph and Purview signals without touching real records.

## Learning outcomes

Explain the purpose in business terms, complete the investigation/build steps, verify the result and document the limitation. Objective references: E02, G01, G02, G03.

## Teaching day

| Session | Activity | Minutes |
|---|---|---|
| Morning | Plain-language briefing, technical concepts, instructor demonstration | 75 |
| Afternoon | Guided build/investigation and validation | 150 |
| Close | Break/fix, evidence, cost and cleanup | 45 |
