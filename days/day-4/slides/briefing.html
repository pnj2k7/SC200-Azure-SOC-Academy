Day 4 / Morning

Why this matters

Different systems describe events differently. This lesson makes their records comparable, as if several departments agreed on the same incident form.

Day 4 / Morning

The mission

A partner gateway and hospital application use different log formats. Bring both into the investigation with a traceable schema.

Day 4 / Morning

Key vocabulary

Schema: the names and types of fields. CEF: a common security-message format. Indicator: a known clue, such as an IP address, that deserves investigation.

Day 4 / Morning

Technical explanation

Source logs, collection transport, transformations and destination schemas are separate failure points. TI matches require field normalization, indicator freshness and context; a match alone is not a verdict.

Day 4 / Afternoon

Practical access

Azure-only custom-log path; optional Linux forwarder, test syslog/CEF sender; threat-intelligence connector permissions.

Day 4 / Afternoon

Demonstrate and verify

The custom table contains the expected rows; demonstrate source, schema and ingestion path for Windows, syslog, CEF, cloud and TI.

Day 4 / Afternoon

Controlled fault

Use a wrong stream name in a single synthetic ingestion request, or map IP to an empty field in a saved query.

Day 4 / Close

Explain the outcome

Delivery is asynchronous; the query can target the wrong table/window, or transformations can filter rows. Check the DCR, stream, timestamps and ingestion errors.
