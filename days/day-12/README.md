# Day 12: Defend the cloud workload

A weak door lock and evidence that someone entered are different findings. Cloud security tools report both weaknesses and suspicious activity; the response must distinguish them.

## Your mission

A workload protection alert points to the application server. Separate a posture weakness from an active incident.

## Learning outcomes

Explain the purpose in business terms, complete the investigation/build steps, verify the result and document the limitation. Objective references: E03.

## Teaching day

| Session | Activity | Minutes |
|---|---|---|
| Morning | Plain-language briefing, technical concepts, instructor demonstration | 75 |
| Afternoon | Guided build/investigation and validation | 150 |
| Close | Break/fix, evidence, cost and cleanup | 45 |
