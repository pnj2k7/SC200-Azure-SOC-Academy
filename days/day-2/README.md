# Day 2: Build the evidence room

A log is a timestamped record of something that happened. Sentinel brings selected records into one place so an analyst can investigate them.

## Your mission

Create the Sentinel workspace and capture the first harmless cloud control-plane change.

## Learning outcomes

Explain the purpose in business terms, complete the investigation/build steps, verify the result and document the limitation. Objective references: B02, C05.

## Teaching day

| Session | Activity | Minutes |
|---|---|---|
| Morning | Plain-language briefing, technical concepts, instructor demonstration | 75 |
| Afternoon | Guided build/investigation and validation | 150 |
| Close | Break/fix, evidence, cost and cleanup | 45 |
